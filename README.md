# R-Projects-for-Data-Analysis
This repository includes R scripts for data cleaning, transformation, and analysis, aimed at generating insights that support informed and strategic decision-making.

It serves as a portfolio of R analytics projects that highlight strong analytical thinking, statistical reasoning, and practical business problem-solving. The projects demonstrate complete analytical workflows — from initial data exploration and preparation to advanced analysis and visualization — covering techniques such as trend analysis, time-series evaluation, cumulative (Pareto) analysis, and regression modeling.

Developed using core R tools and best practices such as tidyverse (dplyr, tidyr) for data wrangling, ggplot2 for professional visualizations, lubridate for time-based analysis, and statistical modeling techniques (e.g., linear regression) to translate business questions into clear, actionable insights.

Important Note: All projects were developed in RStudio, executed locally, and fully documented in  R Markdown notebooks. The work was version-controlled with Git (Bash) and pushed to GitHub to ensure reproducibility, transparency, and clean project tracking.


Below you can find all the projects included on this repository and their corresponding link sources.

     1. India Shoe Shales: https://www.kaggle.com/datasets/nayakganesh007/nike-sales-uncleaned-dataset
     
    This project analyzes a messy and partially synthetic retail shoe sales dataset using R. It demonstrates a full workflow including data cleaning, transformation, exploratory data analysis (EDA), and advanced analytics. The analysis explores product demand, regional revenue distribution, profitability trends, and key sales combinations, while also applying regression and Pareto analysis to extract insights. The focus of the project is on handling imperfect data and demonstrating a structured analytical approach.
